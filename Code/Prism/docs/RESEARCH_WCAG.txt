# WCAG AA 对比度验证
## 1. WCAG AA 对比度验证

### 1.1 验证结果总览

使用相对亮度算法验证莫兰迪色系色彩组合对 WCAG AA 标准的符合情况。计算公式：

\\\
L = 0.2126 × R_linear + 0.7152 × G_linear + 0.0722 × B_linear
对比度 = (L_light + 0.05) / (L_dark + 0.05)
\\\

**验证标准：**
- 普通文字（≤18px）：最低要求 **4.5:1**
- 大文字（≥18px）：最低要求 **3:1**
